Mauborgne For Linux Desktops

Your one time codes, on your terms.

Mauborgne generates TOTP and HOTP codes, keeps the secrets in your system keyring, and can sync them across your devices with end to end encryption.

Features

Everything a code generator should be, nothing it shouldn't.

A quiet, native app that does one job and keeps your secrets where they belong.

TOTP and HOTP

Time and counter based codes with SHA-1, SHA-256 and SHA-512, a live countdown, and one click to copy.

Secrets in your keyring

Pad secrets live in libsecret and the Flatpak secrets portal, never in plain files on disk.

Add from a QR code

Pick an image of the QR code, type a setup key, or import an Aegis vault. Nothing leaves your machine.

Export anywhere

Turn a pad into a QR code for another app, or export one or all pads as an encrypted Aegis vault.

Sandboxed

Runs as a Flatpak with only the access it needs, so a compromised page or app can't read your codes.

Cloud Backup

Optional encrypted backup and sync with the Mauborgne apps for Windows and Android, $10 a year.

Cloud Backup

Sync everywhere. Readable nowhere but your devices.

Your pads are encrypted on this device before they are uploaded. The cloud password never leaves it, so even we can't read your backup.

Encrypted on your device

Pads are sealed in an Aegis format vault with a random key, which is itself wrapped with a key only your password can produce.

Stored, never read

The server holds ciphertext and an OPAQUE password record. It can't decrypt a backup, and can't alter one unnoticed.

Synced across devices

Edits merge automatically between Linux, Windows and Android, including deletions and counter positions.

Get Mauborgne for Linux

Install it on your desktop.

This site is for the free and open source Linux desktop client, and it installs from the Flatpak repository below. Mauborgne for Windows and Android are separate apps from the same family that share Cloud Backup.

Linux

Flatpak

Add Mauborgne's own Flatpak repository, hosted right here, then install. Updates arrive with the rest of your apps.

Channels: stable follows releases, beta follows development. Signed images, verified from Flatpak 1.17 (key F6B4 229E 4C6C 38FE). The GNOME runtime is installed from Flathub.

Flatpak older than 1.17?
flatpak remote-add --if-not-exists --user --no-gpg-verify \
  mauborgne oci+https://linux.mauborgne.app

Older versions cannot verify the signatures, so add the remote without verification, then install as shown.

Stable .flatpakrefBeta .flatpakref
flatpak remote-add --user \
  --signature-lookaside=https://linux.mauborgne.app/sigs \
  mauborgne https://linux.mauborgne.app/mauborgne.flatpakrepo
flatpak install --user mauborgne \
  io.github.jhaygood86.mauborgne
